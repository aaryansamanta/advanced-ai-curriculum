## 🎯 Capstone Spotlight — Pneumonia Detection with Chest X-Rays

**Objective:** Develop a Convolutional Neural Network to detect signs of pneumonia in labeled chest X-ray images.

- 🖼️ Preprocessing and analyzing medical image data
- 🏗️ Designing and training CNN architectures
- 📏 Evaluating model performance with appropriate metrics
- 🔁 Iterative experimentation and improvement
- 📄 Documented in a full technical report and presentation slides

> ⚠️ Due to the use of medical imaging data and the research-oriented nature of the work, this capstone is kept separate from public coursework.
